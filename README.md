# ND Burger Hub Website

A responsive, professional one-page restaurant website for ND Burger Hub.

## Files
- index.html
- style.css
- script.js
- images/

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Notes
- The website uses the photos supplied in the conversation.
- The Order Online buttons use the Google ordering link supplied by the owner/user.
- Phone and Google Maps buttons are included.
- Menu tabs, gallery lightbox, mobile navigation and responsive layouts are implemented.
